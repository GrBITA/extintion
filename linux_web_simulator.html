            📁 أوامر التنقل واستعراض المجلدات (Navigation & Listing)
          

          

            

              
pwd

              
عرض مسار مجلد العمل الحالي (Print Working Directory).

            

            

              
ls -la

              
استعراض كافة الملفات والمجلدات بما فيها المخفية مع الصلاحيات والأحجام.

            

            

              
cd [directory]

              
تغيير المجلد الحالي (مثل cd .. أو cd ~).

            

            

              
tree

              
عرض هيكل المجلدات والملفات على شكل شجرة متفرعة.

            

          

        


        
        

          

            📄 إدارة وصناعة الملفات (Files & Directories)
          

          

            

              
mkdir -p [dir]

              
إنشاء مجلد جديد أو مسار مجلدات متداخلة.

            

            

              
touch [filename]

              
إنشاء ملف فارغ جديد أو تحديث وقت تعديله.

            

            

              
cat / head / tail [file]

              
قراءة محتوى الملف كاملاً، أو أول 10 أسطر، أو آخر أسطر.

            

            

              
cp / mv / rm [-r]

              
نسخ، نقل/إعادة تسمية، وحذف الملفات والمجلدات.

            

            

              
nano [file]

              
فتح محرر النصوص التفاعلي لتعديل الملف وحفظه.

            

            

              
chmod [+x | 755] [file]

              
تغيير صلاحيات القراءة، الكتابة، والتنفيذ للملف.

            

          

        


        
        

          

            ⚡ الأنابيب وإعادة التوجيه (Pipes & Redirection)
          

          

            

              
command > file

              
توجيه مخرجات الأمر وحفظها في ملف (استبدال المحتوى).

            

            

              
command >> file

              
إلحاق مخرجات الأمر بنهاية الملف دون حذف ما قبله.

            

            

              
cmd1 | grep "text"

              
تمرير مخرجات الأمر الأول كمدخلات لأمر الفلترة grep.

            

            

              
cmd | wc -l

              
حساب عدد الأسطر الناتجة من مخرجات الأمر.

            

          

        


        
        

          

            ⚙️ معلومات النظام والإدارة (System & Admin)
          

          

            

              
uname -a / hostname

              
معلومات النواة، المعمارية، واسم الجهاز المضيف.

            

            

              
df -h / free -m

              
مراقبة سعة القرص الصلب واستهلاك الذاكرة العشوائية RAM.

            

            

              
ps aux / top / htop

              
عرض العمليات والبرامج النشطة في الخلفية واستخدام المعالج.

            

            

              
sudo apt install [pkg]

              
محاكاة مدير الحزم لتثبيت برامج مثل nginx, git, python3.

            

            

              
neofetch

              
عرض شعار لينوكس الأيقوني مع بطاقة شاملة لمواصفات النظام.

            

            

              
ping / ifconfig / curl

              
أدوات فحص الاتصال بالشبكة وعناوين IP وطلبات الويب.
